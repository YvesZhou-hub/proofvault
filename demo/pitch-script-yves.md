# Yves 的部分：医院场景（约 3 分钟）

> 只用简单常用词，句子都很短。方括号是操作，不用念。
> 「/」短停顿，「//」长停顿。最后一句交给队友。

---

## 开场：问题（约 40 秒）

Good morning, everyone. / I'm Yves, / and this is ProofVault. //

A woman goes to see her doctor. / She says, / "I take fifty milligrams of my heart medicine." //

An AI tool is listening. / But it writes / five hundred. //

That is ten times too much. / And no one sees it. //

Now the wrong number is in her health record. / And records last a long time. / Years later, / people will still trust it. //

---

## 我们的想法（约 20 秒）

Records managers have simple rules. / Every fact needs a source. / Every change needs a history. / And a real person makes the final choice. //

ProofVault puts these rules into AI.

## 演示（约 1 分 50 秒）

[选中病人 #4092 的病历]

[点 Trace in Provenance Map，等动画走完再开口]

Now we follow the mistake down. / Health. / Medicine. / Heart. //

And here it is. / A common AI mistake / when it turns speech into text. //

[按 Esc，点橙色那段]

That is not fair. / And a doctor could miss a heart problem. //

[点 Apply all AI fixes，打开 Version Diff]

We fix the record. / Now we can see the old version / and the new version, / side by side. //

[切到 IM Sign-off，勾 4 项，点 Approve & Seal]

Last, / a records manager checks it, / and signs off. //

The record is locked, / with a full history / of who changed what, / and when. //

Only now / is it safe to keep. //
